# Techनिकी - Tech Community Website

A modern, responsive community website for Amity University Gurugram's tech enthusiasts and professionals.

## 🚀 Features

- **Responsive Design** - Built with Tailwind CSS for mobile-first experience
- **Interactive Team Profiles** - Flip card animations for team member showcase
- **Project Showcase** - Filterable project gallery with categorization
- **Event Management** - Past and upcoming events with registration
- **Certificate Programs** - Skill validation and certification courses
- **Campus Ambassador Program** - Leadership opportunities for students
- **Blog Platform** - Tech articles and community insights
- **Performance Optimized** - Lazy loading and modern web practices

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Tailwind CSS + Custom CSS
- **Animations:** GSAP, AOS (Animate On Scroll)
- **Background Effects:** VANTA.NET
- **Icons:** Custom SVG icons
- **Deployment:** GitHub Pages

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ramachokkalingam/techniki2.git
   cd techniki2
   ```

2. **Open locally:**
   - Open `index.html` in your browser
   - For development, use Live Server extension in VS Code

3. **Deploy:**
   - Push to GitHub Pages
   - Or deploy to any static hosting service
